This portfolio follows a simple principle: less text, clearer information, stronger professional impact.

The design takes inspiration from a soft, modernist visual style, using light backgrounds, muted sage-green accents, readable typography, and recognizable software icons. It is intended to help an interviewer understand the main points of the profile quickly.

Key Features

Single-page layout: All profile information is presented within one webpage.

No page scrolling: The intended desktop layout fits within a fixed viewport.

Compact dropdowns: Experience, projects, education, skills, certificates, and contact details open on the same screen.

Light professional theme: Off-white surfaces, muted green accents, and charcoal text.

Icon-first presentation: Recognizable icons help visitors scan software tools and professional skills quickly.

Concise content: Short descriptions replace lengthy paragraphs wherever practical.

Interviewer-friendly structure: Important profile highlights remain visible while additional details are available through dropdowns.
